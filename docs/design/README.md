# Design

The committed design artifacts for FlowShield — the founding brief, the requirements, and the plan. These are **repo-only** (never packaged into a published crate) and are the primary reference for contributors and maintainers.

| Document | What it is |
|----------|-----------|
| [`charter.md`](charter.md) | The founding **Phase-0 Research & Architecture charter** — the original brief that scoped the project. Preserved as design history. |
| [`Requirements.md`](Requirements.md) | The **Software Requirements Specification (SRS)** — goals, functional/non-functional requirements, personas, use cases, risks, success metrics, and the decision log. Authoritative for *what* FlowShield must do. |
| [`Plan.md`](Plan.md) | The **phased roadmap** — objectives, scope, tasks, and exit criteria per phase, each referencing the ADRs it implements. Authoritative for *how* and *when*. |

Decisions that arise from these documents are recorded as [Architecture Decision Records](../adr/README.md).
