# Examples

Runnable examples demonstrating FlowShield.

**Status:** empty during Phase 0 — examples are added from **Phase 2** onward, landing alongside the features they demonstrate (per the [Plan](../docs/design/Plan.md)). Planned early examples:

- Rate-limiting a background / non-HTTP workload with the in-memory backend (Phase 2).
- Observability wiring (Prometheus + OpenTelemetry) (Phase 3).
- Per-framework middleware: Tower, Axum, Actix (Phase 5).

Each example will be self-contained and referenced from the relevant crate's documentation.
